> HOW IT WORKS

  1. Paste the logger device IDs (max 30).
  2. Press DOWNLOAD PDFs. A real browser on GitHub opens Frigga, searches each ID and exports “Complete data”, up to 5 at a time.
  3. When it finishes, the ZIP with every PDF opens for download. Invalid IDs are skipped.

The first time, add a GitHub key in ⚙. You can close the page: when you come back it still shows the last download.

> SETTINGS

  1. Open create a key on GitHub ↗.
  2. Repository access: Only select repositories → Kuai-Temperature.
  3. Permissions → Repository → Actions: Read and write.
  4. Generate token, copy it and paste it above.

The key is saved only in this browser and can only start downloads in this repository.
